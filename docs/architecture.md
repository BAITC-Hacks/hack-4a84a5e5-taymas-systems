# Архитектура

Один процесс Python, один порт 8000, серверный рендер HTML. Внешних сервисов — только LLM-провайдер, и тот необязателен.

```
┌──────────────┐  HTTP-формы   ┌────────────────────────────────────────────────────┐
│   Браузер    │ ────────────▶ │  FastAPI + Jinja2 · app/main.py · app/templates/   │
│ бизнес /     │ ◀──────────── │  маршруты: конструктор · редактор · каталог · задача│
│ команда      │     HTML      └───────┬───────────────────┬────────────────┬───────┘
└──────────────┘                       │                   │                │
                                       ▼                   ▼                ▼
                          ┌─────────────────┐   ┌──────────────────┐  ┌──────────────────┐
                          │ app/ai.py       │   │ app/rating.py    │  │ app/store.py     │
                          │ вопросы по      │   │ 7 показателей    │  │ JSON-хранилище   │
                          │ пробелам,       │   │ кейса, 0–100,    │  │ drafts · cards · │
                          │ сборка карточки │   │ расшифровка,     │  │ teams · proposals│
                          └───────┬─────────┘   │ уровень          │  └────────┬─────────┘
                                  │             └──────────────────┘           │
                                  ▼                                            ▼
                          ┌─────────────────┐                        ┌──────────────────┐
                          │ app/llm.py      │                        │ data/store.json  │
                          │ OpenAI / NVIDIA │                        │ (из data/seed.json│
                          │ через один SDK; │                        │  при первом старте)│
                          │ нет ключа →     │                        └──────────────────┘
                          │ локальная       │
                          │ заглушка в ai.py│
                          └─────────────────┘
```

## Кто за что отвечает

| Модуль | Ответственность | Кого зовёт |
| --- | --- | --- |
| `app/main.py` | HTTP-маршруты, формы, рендер шаблонов, редиректы, сообщения об ошибках | `ai`, `rating`, `store` |
| `app/ai.py` | Две AI-функции кейса: уточняющие вопросы по пробелам рейтинга и сборка карточки из ответов. Валидация ответа модели, защита от выдуманных фактов, локальная заглушка без ключа | `llm`, `rating` |
| `app/prompts.py` | Тексты системных промптов (показаны в README) | — |
| `app/llm.py` | Единственная точка вызова LLM: провайдер из `.env`, таймауты, ретраи, JSON-режим с валидацией через pydantic | OpenAI SDK |
| `app/rating.py` | Детерминированный рейтинг готовности: веса кейса, правила начисления, подсказки, пороги уровней. Без LLM | — |
| `app/store.py` | Хранилище в одном JSON-файле: CRUD по четырём сущностям, сортировка каталога, атомарная запись | `models` |
| `app/models.py` | pydantic-модели и словари: поля карточки, отрасли, уровни | — |
| `app/config.py` | Переменные окружения | — |
| `data/seed.json` | Синтетические исходные данные по разделу 6 кейса | — |
| `scripts/rescore_seed.py` | Пересчёт баллов сида по текущей формуле | `rating` |

## Поток данных на демо-пути

1. `POST /business/new` → `store.add_draft` → `ai.generate_questions` → страница вопросов
2. `POST /business/drafts/{id}/answers` → `ai.build_card` → `rating.compute_rating` → `store.add_card` → редактор
3. `POST /business/cards/{id}/edit` → `rating.compute_rating` → `store.update_card` (балл пересчитан)
4. `POST /business/cards/{id}/publish` → `status=published` → `/tasks/{id}`
5. `GET /catalog` → `store.list_cards` (по баллу, с фильтрами)
6. `POST /tasks/{id}/proposals` → `store.add_proposal`
7. `POST /proposals/{id}/decision` → `store.update_proposal` (ручное решение бизнеса)

## Почему так

- **Серверный HTML без JS-сборки** — один процесс, воспроизводится одной командой, три потока разработки делятся по файлам.
- **JSON вместо БД** — объём данных кейса умещается в один файл, сид читается человеком, сброс к исходному состоянию — удаление файла.
- **Рейтинг без LLM** — критерий кейса «прозрачен и пересчитывается» требует формулы, которую можно записать в README и покрыть тестами.
- **ИИ необязателен для запуска** — кейс разрешает локальную заглушку; эксперт без ключа проходит сценарий целиком.
