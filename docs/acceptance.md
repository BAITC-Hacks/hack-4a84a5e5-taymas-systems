# Ручная приёмка перед заморозкой

Чеклист для совместного прогона втроём. Каждый пункт проверяется **в браузере руками**, а не тестами:
автотесты уже зелёные, здесь мы ищем то, что они не ловят — путаницу в словах, нелогичный переход,
непонятное сообщение, цифру, которая не сходится с тем, что видит человек.

Ожидаемые значения ниже сверены с кодом на 23.09.2026. Если реальность разошлась — **это находка,
записываем и чиним**, а не подгоняем чеклист.

**Отсечки:** заморозка функциональности 17:30 · чистая сборка 18:00 · финальные коммиты 18:15 · закрытие 18:30.

---

## 0. Подготовка — 2 минуты

- [ ] `git pull` у всех троих, ни у кого нет незакоммиченного
- [ ] `python -m pytest -q` → зелёный, число тестов записать сюда: ______
- [ ] `make gate` → `2 passed`
- [ ] **`make reset`** — обязательно, иначе в каталоге будут висеть задачи от прошлых прогонов

Если `cards_total` не 5 — `make reset` не сработал, состояние старое. Дальше идти нельзя.

## 1. Сквозной сценарий — главное, 20 баллов кейса

Идём ровно по [data/demo-scenario.md](../data/demo-scenario.md), один человек за клавиатурой,
двое смотрят и придираются.

### Черновик и вопросы

- [ ] Главная → «Я представитель бизнеса» → форма
- [ ] Отрасль **Образование**, текст: `Хотим чат-бота для студентов, чтобы отвечал на вопросы.`
- [ ] Вопросов **6**, у каждого видно «Зачем: <показатель> — N баллов»
- [ ] **Первый вопрос цитирует черновик:** «Вы написали „чат-бота для студентов“…» и даёт примеры
      для образования: «журналы, расписание, обращения студентов»
- [ ] Вопрос про потребность помечен **«Это описано частично»**, в «Зачем» есть «начислено 10»
- [ ] Про контекст вопроса **нет** — он уже взят из черновика

### Карточка и рейтинг

- [ ] Отвечаем **только на первый** вопрос, про данные. Текст ответа — из демо-сценария
- [ ] «Собрать карточку» → редактор
- [ ] Балл **30**, уровень **«Черновик»**
- [ ] Расшифровка: контекст и потребность **10 из 20**, данные **20 из 20**, остальные пять по нулю
- [ ] В карточку попало **только сказанное**: пустые поля пустые, ничего не выдумано
- [ ] Список «Что добавить» называет конкретные недостающие сведения
- [ ] У каждого поля видно, к какому показателю оно относится и сколько стоит

### Рост и подтверждение

- [ ] Дозаполняем поля текстами из демо-сценария → «Сохранить и пересчитать»
- [ ] Сообщение **«было 30 → стало 100»**, уровень «Приоритетная»
- [ ] **Проговорить вслух:** до подтверждения балл предварительный, в каталог не ушёл
- [ ] Нажать «Подтвердить и опубликовать» **без галочки** → остаёмся на странице, сообщение
      «Отметьте „Подтверждаю…“», ничего не опубликовалось
- [ ] Поставить галочку → публикация → переход на страницу задачи

### Каталог и позиция

- [ ] На странице задачи: **100 / 100**, «Позиция в каталоге: **1** из 6»
- [ ] Каталог: наша задача **первая**, выделена рамкой как приоритетная
- [ ] Задача «Проверка заявок на микрокредиты» (20 баллов) **видна** с пометкой «требует уточнения» —
      низкий рейтинг не скрывает и не запрещает отклик
- [ ] У карточек видно число откликов

### Отклик и решение бизнеса

- [ ] Отклик от **DataBee**: идея, план, срок, ссылка `https://example.com/databee/bot` → статус «на рассмотрении»
- [ ] Второй отклик от **CivicStack** — число откликов не ограничено
- [ ] «Выбрать команду» для DataBee → «выбрана»; **у CivicStack статус не изменился**
- [ ] «Отклонить» для CivicStack → «отклонена»
- [ ] Под блоком есть подпись, что команду выбирает человек и система не назначает автоматически
- [ ] Повторно нажать решение по уже решённому отклику → сообщение, статус не перезаписался

**Засечь общее время.** Должно уложиться в 5 минут без спешки.

## 4. Некорректный ввод — 25 баллов по двум рубрикам

Проверяем, что система **объясняет**, а не падает и не молчит.

- [ ] Пустой черновик (пробелы) → сообщение, черновик не создан
- [ ] Очень длинный черновик (вставить 5000 символов) → понятное сообщение, не 500
- [ ] Отклик без идеи или без плана → сообщение, **введённое не потерялось**
- [ ] Отклик без выбора команды → сообщение
- [ ] Ссылка на прототип `ftp://example.kz` или `javascript:alert(1)` → сообщение про http/https,
      отклик не создан
- [ ] Адрес `localhost:8000/tasks/nope` → **страница 404 в стиле приложения**, не голый JSON
- [ ] Адрес `localhost:8000/такой-страницы-нет` → та же страница 404
- [ ] В каталоге вручную дописать `?industry=мусор&level=мусор` → каталог полный, код 200, не падает
- [ ] Ввести в черновик `<script>alert(1)</script>` → на странице виден **текст**, окна не выскакивает
- [ ] **F5 на странице после отправки отклика** → дубль не создаётся
