## Шаг 2. Подпись коммитов — самое важное

По правилам хакатона **участие не засчитывается тому, кто не внёс личный вклад в проект**. Вклад подтверждается коммитами. Если git подписан чужим или несуществующим адресом, коммиты человека просто не будут видны как его.

```bash
git config user.name
git config user.email
```

## Шаг 3. Доступ на запись в репозиторий

Проверить, что человек сможет пушить. Безопасный способ, ничего не меняющий:

```bash
git ls-remote --heads origin main
```

Если требует логин и не проходит — человеку нужно настроить доступ к GitHub. Варианты: `gh auth login`, если установлен GitHub CLI, либо personal access token, либо SSH-ключ.

Это **блокирующая** проблема: без права на запись человек не сможет сдать ни одной задачи и его участие не засчитается. Если не решается за несколько минут — пусть напишет капитану.

**Готово когда:** команда отрабатывает и показывает хеш ветки main.

## Шаг 7. Ключи API

Выдаются организатором, активируются человеком по инструкции `prep/ACTIVATION.md` — там весь порядок с персональными ссылками из Telegram-бота. Нужны два ключа: OpenAI и NVIDIA Build.

**Активированный промокод и работающий ключ — разные вещи.** Проверяем живым запросом. Он ничего не стоит, токены не тратятся:

```bash
curl -s -o /dev/null -w "OpenAI: %{http_code}\n" https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"

curl -s -o /dev/null -w "NVIDIA: %{http_code}\n" https://integrate.api.nvidia.com/v1/models \
  -H "Authorization: Bearer $NVIDIA_API_KEY"
```

Ожидаем `200` по обоим. Если `401` — ключ неверный или не активирован. Если переменные пустые — попроси человека их выставить.

Ключ должен жить **только в переменных окружения или в локальном `.env`**. Правилами хакатона прямо запрещено класть ключи в код, репозиторий, презентации и чаты. Файл `.env` уже в `.gitignore`, так что случайно не уедет.

**Готово когда:** оба запроса вернули 200.

## Шаг 8. Сеть на площадке

Сеть проводная, Ethernet. Свои точки доступа, раздача с телефона и личные роутеры запрещены правилами.

```bash
curl -s -o /dev/null -w "github %{http_code} за %{time_total}s\n" https://github.com
curl -s -o /dev/null -w "openai %{http_code} за %{time_total}s\n" https://api.openai.com/v1/models
```

Если человек ещё не подключён проводом — напомни: нужен переходник USB/USB-C → RJ-45, получение IP и DNS должно стоять автоматически (DHCP).

**Готово когда:** оба адреса отвечают, задержка вменяемая.

Человек должен знать, в каких рамках работает. Дай ему прочитать `CLAUDE.md` в корне репозитория, а сам прочитай его целиком — он понадобится тебе весь день.

Три вещи, которые стоит проговорить вслух:

- **Каждый час должен быть коммит.** Час без подтверждённого прогресса — основание для дисквалификации команды
