# Активация OpenAI и NVIDIA — сделать каждому до 13:00

Инструкция для **человека**, не для агента. Делает каждый участник команды сам, на своём аккаунте: Azamat, Дарья, Анель.

Источник — официальная памятка организатора «Активация OpenAI и NVIDIA для участников HackAlem AI». Здесь то же самое, но с порядком действий, проверками и местами, где легко ошибиться.

**Персональные ссылки и промокоды берутся из Telegram-бота хакатона или из личного кабинета на платформе HackAlem AI.** Общей ссылки нет: у каждого своя. Чужой не пользоваться и свою никому не пересылать.

Всего четыре активации. Делать по порядку, весь проход — минут 15.

| № | Что | Зачем нам |
| --- | --- | --- |
| 1 | ChatGPT Pro + Codex | Подписка и агент для разработки |
| 2 | OpenAI API credits | Ключ, которым работает сам проект |
| 3 | NVIDIA Brev | Кредиты на GPU-среду, запасной вариант |
| 4 | NVIDIA Build | Второй ключ API, запасной провайдер LLM |

---

## 1. ChatGPT Pro и Codex

1. Открыть **персональную ссылку ChatGPT Pro** из бота и войти в свой аккаунт ChatGPT.
2. На странице оформления **убедиться, что написано `Due today: $0`**, и только тогда подтверждать подписку.
3. Там же посмотреть **дату следующего списания** и запомнить её.
4. Открыть меню профиля в ChatGPT — должно отображаться **Pro**.
5. Скачать Codex на **chatgpt.com/codex** и войти в **тот же самый аккаунт**.

> **Не подтверждать оформление, если сумма отличается от `$0`.** Это значит, что ссылка открыта не в том аккаунте или промо не подхватилось — иначе спишут деньги с карты. Выйти, войти в правильный аккаунт, открыть ссылку заново.

> Codex обязан быть в **том же** аккаунте, где появился Pro. Если войти в другой — Pro в нём не будет, и это выяснится в самый неподходящий момент.

**Готово когда:** в профиле ChatGPT видно `Pro`, Codex запускается и залогинен в этот же аккаунт.

## 2. OpenAI API credits

Это **отдельная ссылка**, не та же, что для Pro. Подписка Pro кредитов на API не даёт — это разные вещи.

1. Открыть ссылку **API Credits**, войти в **OpenAI Platform** (platform.openai.com).
2. Подтвердить промокод.
3. Проверить: **Billing → Promotions**, начисление должно быть в списке **Applied promotions**.

**Готово когда:** промо видно в `Applied promotions` и баланс кредитов ненулевой.

Ключ для проекта создаётся там же, в разделе **API keys → Create new secret key**. Ключ показывается **один раз** — сразу скопировать и положить в локальный `.env`.

---

## 3. NVIDIA Brev

1. Открыть **промоссылку NVIDIA Brev** из бота, войти в аккаунт NVIDIA. Если попросит — создать **NVIDIA Cloud Account**.
2. Открыть **Billing** → нажать **Redeem Code** → активировать промокод.
3. Проверить, что начисление появилось в **Current Balance**.

**Готово когда:** в `Current Balance` виден ненулевой баланс.

---

## 4. NVIDIA Build

Делается **в том же аккаунте NVIDIA**, что и Brev.

1. Открыть **build.nvidia.com/settings/api-keys**.
2. **API Keys → Generate API Key**, задать название (например `hackalem`) и срок действия — не короче, чем до конца хакатона.
3. Скопировать ключ и сохранить в безопасном месте.

**Готово когда:** ключ создан и скопирован.

## Куда класть ключи

Оба ключа живут **только** в локальном файле `.env` в корне репозитория. Он уже в `.gitignore`, случайно не уедет.

```
OPENAI_API_KEY=sk-...
NVIDIA_API_KEY=nvapi-...
```

Правилами хакатона **прямо запрещено** размещать пароли, ключи и токены в исходном коде, репозиториях, презентациях и чатах. Перед публикацией проект проверяется на их наличие.

Практически это значит:

- ключ не коммитить — ни в код, ни в README, ни в `.env.example`;
- ключ не пересылать в Telegram и не вставлять в тикеты Linear;
- каждый работает со **своим** ключом, потому что проект читает его из окружения, и чей он — коду безразлично;
- после хакатона ключи удалить.

---

## Проверка, что ключ живой

Активированный промокод и работающий ключ — разные вещи. Проверяется одним запросом, токены при этом не тратятся:

```bash
curl -s -o /dev/null -w "OpenAI: %{http_code}\n" https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"

curl -s -o /dev/null -w "NVIDIA: %{http_code}\n" https://integrate.api.nvidia.com/v1/models \
  -H "Authorization: Bearer $NVIDIA_API_KEY"
```

Ожидаем `200` по обоим. `401` — ключ неверный или промо не активировано. Пусто в переменной — ключ не подставлен в окружение.


Если что-то не активируется — **писать капитану сразу**, а не в 13:00. До старта проблему решить можно, после — уже некогда.
