# prep/ — заготовки, созданные до старта соревновательной части

Здесь лежат шаблоны, подготовленные **до** официального начала работы над проектом. Папка вынесена отдельно намеренно: по п. 6.4 Положения использование ранее созданных материалов подлежит раскрытию, и держать их в одном месте — самый простой способ раскрыть их честно и полностью.

Содержимое — общая инфраструктура, не привязанная ни к какому кейсу: шаблон Dockerfile, compose, Makefile, пример переменных окружения и каркас README. Доменной логики здесь нет и быть не должно.

## Что с этим делать в день соревнования

1. Развернуть нужные шаблоны в корень репозитория, подставив выбранный стек
2. Перечислить использованные заготовки в README проекта, в разделе о ранее созданных материалах
3. Дальше работать в корне; эту папку не трогать

## Содержимое

| Файл | Назначение |
| --- | --- |
| `templates/Dockerfile` | Лёгкий образ на Python, версии зафиксированы |
| `templates/docker-compose.yml` | Запуск одной командой |
| `templates/Makefile` | `make run` и `make check` |
| `templates/env.example` | Пример переменных окружения, включая двух провайдеров LLM |
| `templates/dockerignore` | Чтобы в образ не уезжало лишнее |
| `templates/README-PROJECT.md` | Каркас README проекта по критериям оценки |
