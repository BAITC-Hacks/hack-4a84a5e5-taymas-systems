# prep/ — заготовки, созданные до старта соревновательной части

Здесь лежат шаблоны, подготовленные **до** официального начала работы над проектом. Папка вынесена отдельно намеренно: по п. 6.4 Положения использование ранее созданных материалов подлежит раскрытию, и держать их в одном месте — самый простой способ раскрыть их честно и полностью.

Содержимое — общая инфраструктура, не привязанная ни к какому кейсу: шаблон Dockerfile, compose, Makefile, пример переменных окружения и каркас README. Доменной логики здесь нет и быть не должно.


## Что с этим делать в день соревнования

1. Развернуть нужные шаблоны в корень репозитория, подставив выбранный стек
2. Перечислить использованные заготовки в README проекта, в разделе о ранее созданных материалах
3. Дальше работать в корне; эту папку не трогать

## Содержимое

| Файл | Назначение |
| --- | --- |
| `SETUP.md` | Чеклист настройки машины участника. Даётся агенту на чужой машине словами «прочитай и сделай» |
| `ACTIVATION.md` | Активация OpenAI и NVIDIA участником: подписка, кредиты, ключи. Читает человек, не агент |
| `templates/Dockerfile` | Лёгкий образ на Python, версии зафиксированы |
| `templates/docker-compose.yml` | Запуск одной командой |
| `templates/Makefile` | `make run` и `make check` |
| `templates/env.example` | Пример переменных окружения, включая двух провайдеров LLM |
| `templates/dockerignore` | Чтобы в образ не уезжало лишнее |
| `templates/requirements.txt` | Стартовые зависимости с проверенными версиями |
| `templates/BRIEF.md` | Каркас брифа — первый артефакт дня, заполняется за 10 минут |
| `templates/README-PROJECT.md` | Каркас README проекта по критериям оценки |

## Что уже проверено на практике

Прогон 23.09.2026 до старта, на этих шаблонах собран и запущен тестовый проект:

- **Запасной путь без Docker** работает целиком: `venv` → `pip install -r requirements.txt` → запуск → `pytest`. Проверено на Python 3.14
- **Сборка образа без кеша** проходит, заняла 45 секунд на Apple Silicon
- **`make run`** поднимает контейнер, приложение отрабатывает и выходит с кодом 0
- **`make check`** гоняет тесты внутри контейнера
- **`make verify`** (сборка с нуля плюс тесты) проходит целиком — это команда перед закрытием репозитория
- **`.env` в образ не попадает** — `.dockerignore` работает, внутри только `.env.example`
- Версии в `requirements.txt` реально существуют и ставятся без сборки из исходников
- В `openai` 3.19.0 интерфейс клиента прежний: `OpenAI(api_key, base_url, timeout, max_retries)`, `chat.completions.create`. Плюс доступны `responses.create` и `chat.completions.parse`

Тестовый проект после проверки удалён — в репозитории остались только шаблоны.
