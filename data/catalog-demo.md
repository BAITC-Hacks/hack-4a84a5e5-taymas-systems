# Расширенный демонстрационный каталог

40 опубликованных задач, 40 исходных черновиков, 20 команд и 73 отклика. Все организации,
ситуации, контакты, показатели и решения бизнеса синтетические. Описания наборов данных —
часть условий учебных задач, а не обещание скачиваемых CSV, фотографий или документов.

По пять задач в отраслях: образование, финансы, ритейл, логистика, медицина, госуслуги,
промышленность и другое. Баллы: 20, 35, 45, 50, 65, 80, 85, 95 и 100. Неполные карточки
остаются в каталоге; помощник студенту рекомендует только опубликованные задачи от 40 баллов.

## Проверка AI-подбора

Открыть `/assistants/student`. В таблице — подходящие карточки для оценки ответа, а не
заранее зашитые результаты модели. Поиск без ключа работает по словам, с ключом — через LLM.
У каждой рекомендации должна быть проверяемая цитата и ссылка на существующую задачу.

| Запрос | Что можно найти |
| --- | --- |
| Хочу сделать RAG-бота по правилам университета | `c_demo0001`, навигатор первокурсника |
| Интересует казахский язык и распознавание речи | `c_demo0002`, разговорный тренажёр |
| Хочу распознавать чеки и извлекать суммы, OCR | `c_demo0005`, разбор чеков |
| Ищем задачу про компьютерное зрение и пустые полки | `c_demo0009`, контроль полок |
| Хочу анализировать отзывы покупателей на русском и казахском | `c_demo0010`, группировка отзывов |
| Нужна оптимизация расписания разгрузки на складе | `c_demo0015`, окна разгрузки |
| Интересна административная нагрузка клиники без медицинских карт | `c_demo0018`, прогноз регистратуры |
| Хочу сделать доступную навигацию по зданию | `c_demo0025`, маршруты без лестниц |
| Есть опыт анализа временных рядов и датчиков вибрации | `c_demo0027`, аномалии насосов |
| Интересует стройка, фото материалов и накладные | `c_demo0029`, учёт поставок на стройплощадке |
| Хочу распознавать маркировку упаковки для переработки | `c_demo0032`, сортировка вторсырья |
| Хочу собрать культурный маршрут по времени и бюджету | `c_demo0033`, маршрут гостя |

Уточнить запрос вторым сообщением, например: «Нужны именно изображения, не текстовые документы».
Модель должна учитывать уточнение, а не дописывать отсутствующие свойства задач. Запрос
«астрономическая спектроскопия» проверяет отсутствие подходящих задач.

## Коуч, сравнение и решения

- `/business/cards/c_demo0007/coach`: неполная карточка про дубликаты счетов, 35 баллов.
  Проверить вопросы про данные, ограничения и связь с бизнесом; без подтверждения фактов
  баллы в опубликованном каталоге не меняются.
- `/tasks/c_demo0029`: задача про строительные материалы, 100 баллов и два разных отклика.
  Открыть сравнение, изучить планы и сроки; окончательный выбор остаётся за бизнесом.
- `/tasks/c_demo0015`: расписание разгрузки, три отклика и пример принятого предложения.
- `/tasks/c_demo0004`: стажировки, 80 баллов и один ожидающий отклик.
- Первые пять карточек `c_seed0001`–`c_seed0005` сохранены без изменения, поэтому исходный
  сценарий роста рейтинга и сравнения двух предложений по курсам работает как раньше.

Временные отметки откликов идут после публикации задачи, а решения — после отклика.
Знаки «прошла испытание» не подготовлены заранее: запустите настоящее испытание в интерфейсе.

## Загрузка данных

На первом старте приложение копирует `data/seed.json` в `DATA_PATH`. Уже существующее
хранилище автоматически не заменяется. Для отдельного демо без удаления своих карточек:

```bash
DATA_PATH=/tmp/taymas-expanded-demo.json APP_PORT=8002 python -m app
```

Используйте свободный порт и новый путь; если файл по этому пути уже существует, приложение
загрузит его прежнее содержимое. Основной `data/store.json` при таком запуске не меняется.
