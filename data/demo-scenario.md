# Демо-сценарий для защиты (до 5 минут)

Раздел 11 кейса: «участники вводят слабое описание бизнес-задачи, дополняют его и показывают рост
рейтинга. Затем задача публикуется в общем каталоге, студенческая команда самостоятельно отправляет
предложение, а бизнес вручную принимает или отклоняет отклик. Все переходы должны работать в MVP».

Перед показом: `make reset && make run` — состояние сбрасывается к `data/seed.json`.

**Рост, который показываем: 30 «Черновик» → 100 «Приоритетная».** Числа сверены дословным прогоном
на коде main 15:15 (HAC-40): 30 «Черновик» после ответа про данные, 100 «Приоритетная» после
дозаполнения, позиция 1 из 6 в каталоге, весь путь занимает меньше секунды машинного времени. С реальным ключом API
формулировки вопросов и разбивка ответов по полям могут отличаться, поэтому баллы возможны
на несколько единиц другие; уровни при тех же ответах сохраняются. Перед защитой прогнать один раз
и сверить.

---

## 1. Слабый черновик (бизнес) — ~30 с

Главная → «Я представитель бизнеса». Отрасль: **Образование**. Текст:

> Хотим чат-бота для студентов, чтобы отвечал на вопросы.

Нажать «Получить уточняющие вопросы». Система показывает не менее трёх вопросов, каждый закрывает
конкретное поле карточки и выбран по самым весомым пробелам рейтинга.

## 2. Отвечаем не на всё — ~60 с

Система задаёт **шесть** вопросов: данные и материалы · ожидаемый результат · критерии успеха ·
потребность · ограничения · пользователи. Про контекст не спрашивает — его она уже взяла из черновика.

Отвечаем **только на первый, про данные**, остальные пропускаем. Это честный сценарий: бизнес редко
знает всё сразу, и система не обязана требовать полноты.

| Вопрос | Ответ |
| --- | --- |
| «Вы написали „чат-бота для студентов“. Какие данные, примеры или источники вы можете передать команде? Например: журналы, расписание, обращения студентов.» | Есть FAQ на 120 вопросов в Google Docs, расписание на семестр в Excel, лог обращений за год — около 3 000 сообщений. |

Обратить внимание жюри: вопрос **цитирует черновик** и приводит примеры **для отрасли «Образование»** —
даже без ключа API он звучит как заданный про эту задачу, а не как строка из анкеты. Вопрос про
потребность помечен «Это описано частично»: система видит, что контекст в черновике уже есть.

«Собрать карточку» → редактор.

**Ожидаемо: 30 баллов, уровень «Черновик».** Показать три вещи:

- в карточку попало только то, что сказал человек, пустые поля остались пустыми;
- расшифровка объясняет каждый балл: контекст и потребность 10 из 20 (контекст взят из черновика,
  потребность не названа), данные 20 из 20, остальные пять показателей по нулю;
- список недостающих сведений называет, что именно дописать.

## 3. Рост рейтинга (бизнес) — ~70 с

Дописываем в редакторе то, на что не ответили:

| Поле | Текст |
| --- | --- |
| Потребность | Нужно разгрузить деканат и отвечать на типовые вопросы сразу, без участия сотрудника. |
| Ожидаемый результат | Телеграм-бот, который отвечает на типовые вопросы и передаёт сложные оператору; админ-панель для обновления FAQ. |
| Критерии успеха | Не менее 60% вопросов закрываются без оператора; среднее время ответа до 1 минуты. |
| Пользователи | Студенты всех курсов (около 2 500 человек) и сотрудники деканата. |
| Ограничения | Срок — 8 недель. Telegram как основной канал. Персональные данные студентов в бот не передаются. |
| Контакт | Дана Абенова, начальник учебного отдела, d.abenova@example.kz |
| Формат взаимодействия | Созвон раз в неделю, вопросы в чате, демо каждые две недели. |

«Сохранить» → предварительный балл **100**, уровень «Приоритетная».

Здесь проговорить главное правило кейса: баллы засчитываются только за **подтверждённые** поля.
До подтверждения балл предварительный, в каталог он не уходит.

Отметить «Подтверждаю, что карточка составлена верно» → «Подтвердить и опубликовать».

## 4. Каталог (команда) — ~30 с

Открывается страница задачи → «Каталог задач». Наша задача на первой позиции, выделена как
приоритетная. Показать фильтр по уровню и по отрасли. Задача «Проверка заявок на микрокредиты»
(20 баллов) из сид-данных видна в каталоге с пометкой «требует уточнения»: низкий рейтинг
не скрывает задачу и не запрещает отклик.

## 5. Отклик команды — ~45 с

Раздел «Я команда»: команда **DataBee**, идея «Бот на FastAPI с поиском по FAQ и передачей сложных
вопросов оператору», план «2 недели — FAQ и расписание, 2 недели — оператор и панель, 2 недели —
пилот», срок «6 недель», ссылка `https://example.com/databee/bot`.

«Отправить отклик» → статус «на рассмотрении». Отправить второй отклик от **CivicStack**, чтобы
было из чего выбирать.

## 6. Решение бизнеса — ~30 с

Раздел «Решение бизнеса»: «Выбрать команду» для DataBee → статус «выбрана». «Отклонить» для второго
→ «отклонена». Подчеркнуть: можно выбрать одну, несколько или ни одной команды, система не назначает
исполнителей автоматически.

## 7. Испытание задачи — сверх сценария, ~40 с

Показать, если остаётся время или спрашивают «а что ещё, кроме рейтинга». В редакторе слабой
карточки (после шага 2, на 30 баллах) нажать «Проверить глазами команды →», выбрать DataBee, отправить.

Что видим: «Не выдержала», план первой недели с шагом «Стоп», блокеры с ценой в баллах, следующий
шаг с целевым баллом и уровнем.

Что говорим: «Это юнит-тест для бизнес-задачи: до публикации её пробует взять виртуальная студенческая
команда и говорит, где застрянет. Баллы за это не начисляются — только за подтверждённые поля, как
требует кейс. ИИ не добавляет фактов: план строится из карточки, ответ с числами не из карточки
отбрасывается. Без ключа то же самое делает заглушка».

После дозаполнения (шаг 3) повторить: «Выдержала», в каталоге у задачи знак «прошла испытание».

## Что сказать в конце — ~15 с

- Рейтинг прозрачный: семь показателей кейса с весами 20/20/15/15/10/10/10, пороги уровней 40/70/90,
  пересчёт после каждого подтверждённого дополнения, позиция в каталоге меняется вместе с баллом.
- Баллы даются не за факт заполнения: за данные без формата и объёма начисляется половина веса,
  за критерии успеха без измеримого признака — тоже.
- ИИ задаёт вопросы и раскладывает ответы по полям, фактов не добавляет, текст подтверждает человек.
- Без ключа API работает локальная заглушка, сценарий проходит целиком.
