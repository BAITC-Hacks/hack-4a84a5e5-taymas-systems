# Демо-сценарий для защиты (до 5 минут)

Раздел 11 кейса: «участники вводят слабое описание бизнес-задачи, дополняют его и показывают рост
рейтинга. Затем задача публикуется в общем каталоге, студенческая команда самостоятельно отправляет
предложение, а бизнес вручную принимает или отклоняет отклик. Все переходы должны работать в MVP».

Перед показом: `make reset && make run` — состояние сбрасывается к `data/seed.json`.

## 1. Слабый черновик (бизнес) — ~30 с

Главная → «Я представитель бизнеса». Отрасль: **Образование**. Текст:

> Хотим чат-бота для студентов, чтобы отвечал на вопросы.

Нажать «Получить уточняющие вопросы». Система показывает ≥ 3 вопроса по самым весомым пробелам.

## 2. Ответы на вопросы — ~60 с

Отвечаем на три-четыре вопроса (формулировки вопросов зависят от режима ИИ, поля — те же):

| Поле | Ответ |
| --- | --- |
| Контекст / потребность | Сейчас студенты пишут в деканат в WhatsApp и на почту, ответы приходят через 2–3 дня, 80% вопросов повторяются: расписание, справки, пересдачи. Нужно разгрузить деканат и отвечать сразу. |
| Данные и материалы | Есть FAQ на 120 вопросов в Google Docs, расписание на семестр в Excel, лог обращений за год — около 3 000 сообщений. |
| Ожидаемый результат | Телеграм-бот, который отвечает на типовые вопросы и передаёт сложные оператору; админ-панель для обновления FAQ. |
| Критерии успеха | Не менее 60% вопросов закрываются без оператора; среднее время ответа до 1 минуты. |

«Собрать карточку» → редактор карточки. Показать: карточка собрана только из наших слов, балл и уровень (ожидаем **«рабочая»**), панель показывает, где недобор.

## 3. Рост рейтинга (бизнес) — ~60 с

В редакторе дописать оставшиеся поля:

| Поле | Текст |
| --- | --- |
| Пользователи | Студенты всех курсов (около 2 500 человек) и сотрудники деканата. |
| Ограничения | Срок — 8 недель. Telegram как основной канал. Персональные данные студентов в бот не передаются. |
| Контакт | Дана Абенова, начальник учебного отдела, d.abenova@example.kz |
| Формат взаимодействия | Созвон раз в неделю, вопросы в чате, демо каждые две недели. |

«Сохранить» → сообщение «Рейтинг пересчитан: было N → стало M», уровень **«приоритетная»** (90–100).
Отметить «Подтверждаю…» → «Подтвердить и опубликовать».

## 4. Каталог (команда) — ~30 с

Открывается страница задачи → перейти в «Каталог задач». Наша задача — на первой позиции с выделением.
Показать фильтр по уровню («Приоритетная») и по отрасли. Черновик «Проверка заявок на микрокредиты» виден, но помечен «требует уточнения».

## 5. Отклик команды — ~45 с

Открыть нашу задачу → раздел «Я команда»: команда **DataBee**, идея: «Бот на FastAPI с поиском по FAQ и передачей сложных вопросов оператору», план: «2 недели — FAQ и расписание, 2 недели — оператор и панель, 2 недели — пилот», срок: «6 недель», ссылка: `https://example.com/databee/bot`. «Отправить отклик» → отклик со статусом «на рассмотрении».

Можно отправить второй отклик от **CivicStack**, чтобы показать сравнение.

## 6. Решение бизнеса — ~30 с

Раздел «Решение бизнеса»: «Выбрать команду» для DataBee → статус «выбрана»; «Отклонить» для второго → «отклонена».
Подпись: система не назначает команды автоматически — выбирает бизнес.

## Что сказать в конце — ~15 с

- Рейтинг прозрачный: семь показателей кейса, веса 20/20/15/15/10/10/10, пороги уровней 40/70/90, пересчёт после каждого подтверждения.
- ИИ только задаёт вопросы и раскладывает ответы по полям; фактов не добавляет, текст подтверждает человек.
- Без ключа API работает локальная заглушка — сценарий проходит целиком.
