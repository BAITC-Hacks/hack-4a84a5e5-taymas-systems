## Принятые решения

Что решили и почему. Нужно, чтобы не переобсуждать одно и то же и чтобы README потом собирался из готового.

| Решение | Причина | Когда |
| --- | --- | --- |
| Трек 07 «Образование» | Выбор команды, не окончательный | до старта |
| Docker как основной путь запуска + запасной путь без него | Критерий воспроизводимости, 20 баллов. Запасной путь — страховка от окружения эксперта | до старта |
| Ветку заводит исполнитель, как ему удобно; готовое сразу в main | Без ревью и PR — на это нет времени. Интеграция не откладывается на конец | до старта |
| Потоки работы и лейны нарезаются в фазе 0, а не заранее | Слои решения видно только по кейсу. Жёсткое закрепление людей за ролями привело бы к простою и к работе не над тем | до старта |
| Один провайдер в критическом пути — OpenAI | Два провайдера на основном сценарии = два способа упасть. NVIDIA по назначению: эмбеддинги, массовые вызовы, речь, резерв | до старта |
| FastAPI + Jinja2, серверный HTML, без Node | Один процесс, один порт, одна команда запуска; три лейна делятся по файлам без конфликтов | 13:25 |
| JSON-хранилище вместо БД | Сид-данные кейса (5×4 сущностей) — это буквально начальный файл; SQL за 5 часов не окупается | 13:25 |
| Рейтинг детерминированный, без LLM | Критерий «прозрачен, пересчитывается» на 25 баллов — правила должны быть объяснимы в README и покрыты тестами | 13:25 |
| ИИ: две функции (вопросы, сборка карточки) + локальная заглушка без ключа | Кейс требует минимум одну и разрешает заглушку; эксперт без ключа всё равно проходит сценарий | 13:25 |
| `.env` необязателен для `docker compose up` | Воспроизводимость: без ключа — режим заглушки, а не падение | 13:35 |
